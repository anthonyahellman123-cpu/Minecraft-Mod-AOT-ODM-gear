# ODM Gear model sources

Open `odm_harness.bbmodel` in Blockbench. The model is an original industrial ODM-inspired rig built around Minecraft player proportions.

The first pass contains:

- waist belt and reinforced backplate
- independent left and right hip gearboxes
- twin angled gas canisters with removable caps
- blade housings
- gas nozzles, center valve, and feed hoses
- left and right grapple ports

The linked 64×64 texture lives at `src/main/resources/assets/odmgear/textures/entity/odm_harness.png`.
